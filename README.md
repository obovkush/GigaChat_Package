# GigaChat API Клиент (версия с пакетом)

Простое консольное приложение для взаимодействия с GigaChat API с использованием официального пакета GigaChat.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` в корневой директории проекта и добавьте ваш API ключ:
```
GIGACHAT_API_KEY=your_api_key_here
```

## Использование

Запустите приложение:
```bash
python gigachat_package_client.py
```

Введите ваше сообщение и нажмите Enter. Для выхода введите 'exit'.

## Функциональность

- Отправка сообщений в GigaChat API через официальный пакет
- Получение и отображение ответов
- Обработка ошибок
- Простой консольный интерфейс

## Отличия от версии с REST API

Эта версия использует официальный пакет GigaChat, который:
- Автоматически управляет токенами доступа
- Предоставляет более удобный интерфейс
- Обрабатывает ошибки на уровне пакета
- Не требует ручной работы с HTTP-запросами
